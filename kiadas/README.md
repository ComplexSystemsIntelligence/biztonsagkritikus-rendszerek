# A kiadás olvasható változata

Ez a mappa a legutóbbi kiadás lefordított könyveit tartalmazza, hogy a Zenodo a forrással együtt az olvasható
változatot is archiválja:

- `biztonsagkritikus-rendszerek-kezikonyv.pdf` – a kézikönyv nyomtatható változata (A4)
- `biztonsagkritikus-rendszerek-kezikonyv.epub` – a kézikönyv e-könyv-olvasóra
- `biztonsagkritikus-rendszerek-gyakorlat.pdf` – a gyakorlati útmutató

A mindig friss webes változat: <https://complexsystemsintelligence.github.io/biztonsagkritikus-rendszerek/>

A fájlokat a tároló gyökerében futtatott `./kiadas.sh` állítja elő, minden kiadás előtt.
